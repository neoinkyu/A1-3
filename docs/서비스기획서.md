# A1-3 서비스 기획서

## 1. 서비스 개요

* **과제명:** AI 웹 개발: 내 아이디어를 현실로, AI 웹 서비스 빌딩
* **과제 고유번호:** A1-3
* **서비스명:** 파산픽 AI
* **서비스 유형:** AI 기반 파산재단 매각물건 검색·추천 웹 서비스
* **배포 환경:** Vercel
* **배포 URL:** https://a1-3-xi.vercel.app
* **GitHub Repository:** A1-3

파산픽 AI는 사용자가 원하는 파산재단 매각물건의 조건을 자연어로 입력하면, Gemini AI가 검색 의도를 분석하고 구조화한 후 샘플 데이터베이스에서 조건에 맞는 매각물건을 찾아주는 웹 서비스이다.

예를 들어 사용자가 다음과 같이 입력할 수 있다.

> 대전하고 세종에서 5천만원 이하 부동산 찾아줘.

AI는 위 문장에서 지역, 자산유형, 최대가격 등의 검색조건을 추출하고 해당 조건에 맞는 매각물건을 검색한다.

---

## 2. 서비스 개발 목적

파산재단 매각공고에는 부동산뿐만 아니라 채권, 지식재산권, 주식, 자동차, 기계기구 등 다양한 자산이 포함될 수 있다.

또한 실제 매각공고는 게시글과 첨부파일 형태로 제공되는 경우가 많아 사용자가 여러 공고를 비교하거나 원하는 조건의 물건을 빠르게 찾는 데 불편함이 있다.

파산픽 AI는 이러한 문제를 해결하기 위해 다음과 같은 방향으로 기획하였다.

1. 파산재단 매각정보를 구조화된 데이터로 관리한다.
2. 사용자가 복잡한 검색 필터 대신 자연어로 원하는 조건을 입력할 수 있도록 한다.
3. AI가 자연어를 검색조건으로 변환한다.
4. 프로그램이 실제 데이터에서 조건에 부합하는 물건을 검색한다.
5. 검색 결과를 사용자가 쉽게 비교할 수 있는 카드 형태로 제공한다.

## 5. 핵심 기능

### 5.1 자연어 검색

사용자는 복잡한 검색 필터를 직접 설정하지 않고 일반적인 문장으로 원하는 물건을 검색할 수 있다.

예시:

> 대전하고 세종에서 5천만원 이하 부동산 찾아줘.

> 천만원 안쪽으로 살 수 있는 특허 물건 있어?

> 차량 중에서 제일 싼 것부터 보여줘.

---

### 5.2 AI 검색조건 분석

Gemini API를 이용하여 사용자의 자연어 입력을 구조화된 검색조건으로 변환한다.

예시 입력:

> 대전하고 세종에서 5천만원 이하 부동산 찾아줘.

AI 분석 결과:

```json
{
  "regions": ["대전", "세종"],
  "category": "부동산",
  "subcategory": null,
  "max_price": 50000000,
  "min_price": null,
  "bid_within_days": null,
  "sort": "bid_date"
}
```

---

### 5.3 데이터 검색

AI가 직접 매각물건을 생성하지 않는다.

AI는 검색조건만 분석하고, 실제 물건 검색은 Python 프로그램이 샘플 데이터베이스를 대상으로 수행한다.

이를 통해 AI가 존재하지 않는 물건을 임의로 생성하는 문제를 줄이고 검색 결과의 일관성을 확보한다.

---

* 최저입찰가
* 관할법원

## 6. AI 기능 설계

### 6.1 입력

사용자가 검색창에 입력한 자연어 문장

예:

> 대전·세종에 있는 5천만원 이하 부동산 중 입찰일이 가까운 물건 추천해줘.

### 6.2 AI 처리

Gemini API가 자연어를 분석하여 다음 조건을 추출한다.

* 지역
* 자산 대분류
* 자산 세부분류
* 최대가격
* 최소가격
* 입찰기간
* 정렬기준

### 6.3 데이터 처리

Gemini가 반환한 검색조건을 Python 백엔드가 전달받는다.

Python은 `data/auctions.json`에 저장된 샘플 파산재단 매각물건을 검색하고 조건에 맞는 물건을 필터링한다.

### 6.4 출력

검색조건과 조건에 맞는 매각물건을 웹 화면에 표시한다.

전체 처리 흐름은 다음과 같다.

```text
사용자 자연어 입력
        ↓
JavaScript
        ↓
fetch('/api/search')
        ↓
Vercel Serverless Function
        ↓
Python
        ↓
Gemini API
        ↓
검색조건 JSON 생성
        ↓
Python DB 검색
        ↓
auctions.json
        ↓
검색 결과 반환
        ↓
JavaScript
        ↓
웹 화면 출력
```

## 7. AI 기능 실패 처리 기준

### 7.1 빈 입력

사용자가 아무 내용도 입력하지 않은 경우 API를 호출하지 않는다.

안내 문구:

> 검색 조건을 입력해주세요.

---

### 7.2 API 오류

Gemini API 또는 Python Serverless Function에서 오류가 발생한 경우 사용자에게 내부 오류 상세정보를 노출하지 않는다.

안내 문구:

> AI 검색 중 오류가 발생했습니다. 잠시 후 다시 시도해주세요.

---

### 7.3 응답 지연

AI API 요청이 30초 이상 완료되지 않을 경우 JavaScript의 `AbortController`를 이용해 요청을 종료한다.

안내 문구:

> 응답이 지연되고 있습니다. 잠시 후 다시 시도해주세요.

---

### 7.4 검색 결과 없음

사용자가 입력한 조건에 맞는 물건이 없는 경우 검색조건을 완화하도록 안내한다.

안내 문구:

> 조건에 맞는 매각물건을 찾지 못했습니다. 지역이나 가격 조건을 넓혀서 다시 검색해보세요.

## 10. API 키 및 보안

Gemini API 키는 소스코드에 직접 입력하지 않는다.

Vercel의 Environment Variables를 이용하여 다음 환경변수로 관리한다.

```text
GEMINI_API_KEY
```

로컬 개발환경에서도 환경변수를 사용하며 `.env` 관련 파일은 `.gitignore`를 통해 GitHub에 업로드되지 않도록 한다.

주요 제외 항목:

```text
.env
.env.*
.vercel
```

사용자가 AI 검색창에 입력한 자연어 문장 전체는 Google Analytics로 전송하지 않는다.

## 13. 향후 확장 방향

현재는 교육용 JSON 데이터베이스를 사용하지만, 실제 서비스로 발전시키는 경우 다음과 같이 확장할 수 있다.

```text
대법원 파산재단 매각공고
        ↓
공고 및 PDF 수집
        ↓
AI 문서 분석
        ↓
구조화된 DB 저장
        ↓
자연어 검색
        ↓
AI 추천·비교
```

실제 공고문에서 다음과 같은 정보를 추출하여 데이터베이스화할 수 있다.

* 관할법원
* 사건번호
* 파산관재인
* 관재인 연락처
* 관재인 주소
* 매각자산 유형
* 물건 소재지
* 감정가 또는 기준가
* 최저입찰가격
* 입찰일
* 입찰회차
* 입찰방법
* 입찰보증금

## 14. 서비스 이용 안내

본 서비스는 AI 웹 개발 교육과제 수행을 위한 프로젝트이다.

현재 제공되는 모든 매각물건 정보는 교육 목적으로 생성된 가상 데이터이며 실제 법원, 파산사건 또는 파산재단 매각공고와 관련이 없다.

실제 서비스로 운영할 경우 이용자는 반드시 법원 및 파산관재인이 제공하는 최신 원문 공고를 확인해야 하며, 서비스의 검색 및 AI 분석 결과만으로 투자 또는 법률적 판단을 해서는 안 된다.
